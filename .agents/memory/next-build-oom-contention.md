---
name: Next build OOM contention
description: Cold Turbopack build OOMs were caused by Tailwind v4 auto source detection scanning the multi-GB .local/.cache dirs (~4.4GB of the ~6.5GB peak); fixed via source(none) + explicit @source globs in globals.css — cold build now ~2.1GB.
---

Cold `next build` (Turbopack, Next 16.3.4) used to peak ~6.5GB and coin-flip SIGKILL. Bisected 2026-09: the app JS graph is NOT the problem — a trivial 1-page app with the real `_app.tsx` still peaked ~5.9GB, and excluding all 203 API routes moved the peak <3%. The dominant contributor was the `globals.css` compile: bare `@import "tailwindcss"` alone cost ~4.4GB because Tailwind v4 automatic source detection walked the whole workspace, including the multi-GB `.local/` and `.cache/` dirs (not covered by .gitignore-driven ignores), turning junk text into false-positive utility candidates — which also bloated the shipped CSS by ~107KB of garbage rules. Fix: `@import "tailwindcss" source(none)` + explicit `@source` globs mirroring tailwind.config content globs. Result: cold build ~2.1GB peak, ~40s wall (was ~6.5GB, ~4min).

**Why:** Turbopack build memory here is native (V8 heap stayed ~64MB — heap caps are irrelevant) and scales with what gets parsed/scanned, not with route count. Neither `bundlePagesRouterDependencies` (Turbopack ignores it for pages builds), `optimizePackageImports` (@heroui barrel), nor `turbopackPluginRuntimeStrategy` (workerThreads vs childProcesses — the PostCSS child balloons either way) moved the peak.

**How to apply:** if build memory regresses, measure first with scripts/measure-build-peak.sh (RSS sampler + --experimental-debug-memory-usage; process is named `next-build`, not `next build`) and bisect with `--debug-build-paths`. When editing tailwind.config.ts `content` globs, mirror the change into the `@source` lines in styles/globals.css. Verify CSS parity by selector-diffing `.next/static/chunks/*.css` against a known-good build, not byte size. The dev-server.sh supervisor (port-first status page, memory gate at 3000MB, IDE kill, retries, last-good fallback) stays as a host-noise safety net; keep scripts/dev-server.test.sh green when touching it.
